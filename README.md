# SW4DX Singularity — 전국무쌍 4 DX 특이점 모드

NPC 무장이 평타·차지·신속·영기·무쌍난무를 상황에 맞게 사용하도록 전투 AI를 확장하는 모드입니다. 공격 연계, 추격, 방어와 회피를 함께 다뤄 장수전의 긴장감을 높입니다.

**첫 공개 버전: v1.0.0** · 대상: SAMURAI WARRIORS 4 DX / Steam / Windows 64비트

## 주요 기능

- **공격 연계**: 평타와 차지를 연결하고, 상대의 피격·공중 상태를 보고 후속 공격을 선택합니다.
- **신속 추격**: 거리가 벌어진 상대 무장을 신속으로 추격하며, 해당 무브셋에서 지원하는 신속 차지 분기를 활용합니다.
- **가드 대응**: 상대가 가드를 유지하면 영기로 방어를 깨는 공격을 시도합니다.
- **회피와 반격**: 피격·가드 중 영기 회피, 가드 이동과 스텝을 사용합니다. 영기 회피 후 반격 확률은 50%입니다.
- **살진**: 상대가 살진을 받을 수 있는 경직 상태에 들어가면 공격을 시도합니다.
- **장수 간 전투 배분**: 다대다 전투에서 상대를 나누어 맡고, 보조 공격의 빈도를 조절합니다.
- **승하마 판단**: 가까운 전투에서는 말에서 내려 싸우고, 안전한 이동 상황에서는 기억하고 있는 말에 다시 타는 행동을 판단합니다.
- **영기 표시**: 무장 머리 위와 좌상단 대상 체력바에 영기를 표시합니다. 추가 무쌍 게이지는 표시하지 않습니다.

실제 무쌍·영기 잔량과 게임의 기술 소모 판정을 사용합니다. 플레이어를 직접 조작하거나 세이브 파일을 편집하는 방식은 아닙니다.

## 무장 성향과 시작 자원

| 유형 | 전투 성향 | 시작 무쌍 | 시작 영기 |
| --- | --- | --- | --- |
| 맹장형 | 평타·차지와 적극적인 무쌍 사용 | 1회분 | 5칸 가득 |
| 밸런스형 | 공격·추격·방어를 균형 있게 선택 | 0.5회분 | 5칸 가득 |
| 책사형 | 영기 가드 브레이크와 상대 공격에 대응하는 무쌍 | 0 | 5칸 가득 |
| 닌자형 | 신속·신속 차지를 적극 활용 | 0.5회분 | 5칸 가득 |

무쌍 1회분은 1000입니다. 시작 자원은 NPC 생성 시 한 번만 지급하며, 이후에는 게임의 충전·소비를 따릅니다. 영기는 각 무장의 실제 최대치까지 채워 표시상 5칸이 모두 찹니다.

아군·적군 NPC에 적용합니다. 플레이어와 전환 가능한 파트너의 시작 자원은 직접 변경하지 않으며, 파트너의 전투 행동은 게임의 기본 AI를 따릅니다. 클론 무장에는 세 유형을 균형 있게 배분하고, 지정된 닌자형을 유지합니다. 전체 유형표는 [무장 유형표](docs/OFFICER_STYLES.md)에서 확인할 수 있습니다.

## 무쌍난무 사용 대상

모드가 요청하는 완전한 무쌍난무는 무쌍무장 55명과 아래 클론 12명에게 허용됩니다.

우에스기 카게토라, 다카하시 쇼운, 류조지 다카노부, 나베시마 나오시게, 모가미 요시아키, 스에 하루카타, 사이토 도산, 다케다 카츠요리, 사이토 타츠오키, 히로나카 다카카네, 사나다 마사유키, 아사쿠라 요시카게.

일반 클론은 평타·차지·신속·영기 등으로 싸웁니다. 무쌍의 사용 시점은 허용된 무장의 성향과 전투 상황에 따라 달라집니다.

## 설치

1. Releases에서 **SW4DX_Singularity_v1.0.0.zip**을 내려받아 압축을 풉니다.
2. 게임을 종료합니다.
3. `D3DCompiler_43.dll`, `SW4DX_Singularity.dll`, `SW4DX_Singularity.ini` 세 파일을 `SamuraiWarriors4DX.exe`가 있는 폴더에 복사합니다.
4. 게임을 실행하면 자동으로 적용됩니다. 별도 실행 프로그램이나 조작 키는 필요하지 않습니다.

이미 이 모드의 로더와 설정 파일을 사용 중이면 **`SW4DX_Singularity.dll`만 교체**해도 됩니다. 같은 이름의 다른 로더를 사용하는 경우에는 덮어쓰기 전에 파일 구성을 확인하세요. 기존 파일을 교체할 때는 원본을 따로 보관해 주세요.

| 파일 | 역할 |
| --- | --- |
| `D3DCompiler_43.dll` | 게임 실행 시 모드 DLL을 불러오는 로더 |
| `SW4DX_Singularity.dll` | 전투 AI와 영기 표시 |
| `SW4DX_Singularity.ini` | 기능 사용 여부와 무장 유형 설정 |

게임 실행 파일이나 세이브 파일은 덮어쓰지 않습니다. 3Dmigoto는 필수 조건이 아닙니다.

## 설정

게임 폴더의 `SW4DX_Singularity.ini`를 편집한 뒤 게임을 다시 실행합니다. 기능 설정은 `1`이면 사용, `0`이면 사용하지 않습니다.

| 설정 | 기능 |
| --- | --- |
| `Enabled` | 모드 전체 사용 여부 |
| `NormalCombos` | 평타·차지 연계 |
| `HyperChains` | 신속 연계·추격 |
| `TacticalMusou` | 상황별 무쌍난무 사용 |
| `GuardBreak` | 영기 가드 브레이크 |
| `PressureEscape` | 압박 상황의 영기 회피 |
| `ReactiveMovement` | 가드 이동·스텝·거리 조절 |
| `AutoMount` | NPC 승하마 판단 |
| `OfficerTypes` | 네 가지 전투 성향 |
| `OfficerCoordination` | 장수 간 상대 배분과 보조 공격 조절 |
| `DuelHyperHalf` | 무장전의 신속 빈도 조절 |
| `NpcSaljin` | NPC 살진 시도 |
| `NpcSaljinCamera` | 조건이 맞는 NPC 살진에서 게임의 전용 카메라 사용 |
| `ResourceHUD` | NPC 영기 게이지 표시 |

`[OfficerTypes]`의 값은 `0=밸런스`, `1=맹장`, `2=책사`, `3=닌자`입니다. 무장 유형을 바꿔도 무쌍난무 허용 명단은 바뀌지 않습니다.

## 모드 끄기와 제거

잠시 끄려면 `SW4DX_Singularity.ini`의 `[Singularity]`에서 `Enabled=0`으로 바꾸고 게임을 다시 실행합니다.

완전히 제거하려면 게임 종료 후 이 패키지에서 복사한 세 파일을 제거합니다. 설치 전에 같은 이름의 파일이 있었다면 보관해 둔 원본으로 복원하세요.

## 호환성과 확인 사항

지원하는 Steam 실행 파일을 기준으로 동작하며, 다른 실행 파일에서는 연결을 중단합니다. 호전성 설정을 변경하는 모드와는 별도로 동작하고, 호전성 모드의 적용 여부에 따라 체감 난이도는 달라질 수 있습니다.

병사 AI 모듈은 포함하지 않습니다. 무브셋이 지원하지 않는 기술이나 말 소환 행동을 새로 만들지는 않습니다. 음성·카메라·연계의 표현은 무장과 전투 상황에 따라 차이가 있을 수 있습니다.

문제를 제보할 때 게임 모드·전장·무장 이름, 재현 상황, 함께 사용한 모드를 적고 게임 폴더의 `SW4DX_Singularity.log`를 첨부해 주세요.

## 빌드

소스는 GitHub 저장소의 `src` 폴더에 있습니다. Windows에서 Zig 0.13.0으로 빌드할 수 있습니다.

```powershell
.\build.ps1 -Zig "C:\path\to\zig.exe"
```

결과물은 `dist` 폴더에 생성됩니다. 게임 실행 파일·세이브·개인 실행 기록은 저장소에 포함하지 않습니다.
